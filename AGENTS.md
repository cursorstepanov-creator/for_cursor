# AGENTS.md

## Обзор репозитория

Это не программный проект, а личная база знаний **Life OS** — набор Markdown-файлов,
которые агент читает и обновляет как долговременную память пользователя.

- Здесь **нет** кода приложения, менеджера пакетов, зависимостей, тестов, сборки и линтера.
- "Приложение" — это папка `life-os/` плюс поведение агента, заданное в
  `.cursor/rules/life-os.mdc`.

Структура `life-os/`:

- `profile/` — долговременные факты о пользователе.
- `inbox/inbox.md` — быстрый ввод (мысли, задачи, идеи, покупки).
- `tasks/` — текущие, отложенные и повторяющиеся задачи.
- `notes/` — идеи, решения, покупки.
- `reviews/` — итоги дня и недели.

## Cursor Cloud specific instructions

- Устанавливать/собирать/тестировать нечего: нет зависимостей, тестов, линтера и сервисов.
  Update script намеренно является no-op.
- "Запуск приложения" в этом репозитории = выполнение рабочего процесса памяти по правилам
  из `.cursor/rules/life-os.mdc`: положить запись в правильный файл в правильном формате
  (например, быструю заметку — в `life-os/inbox/inbox.md` под `## Новые записи`).
- Правило `.cursor/rules/life-os.mdc` имеет `alwaysApply: true` и применяется автоматически.
- Не сохранять секреты: пароли, токены, банковские/паспортные данные, приватные мед. документы.
